🎥 Movie Rating Prediction System

Movie Rating Predictor Pro is a Machine Learning based web application developed using Python and Flask. It predicts movie ratings based on movie information and previously available movie data.

The system uses the Linear Regression algorithm to estimate the expected movie rating from the selected input features.

Algorithm: Linear Regression

Framework: Flask

Language: Python

ML Library: Scikit-learn
