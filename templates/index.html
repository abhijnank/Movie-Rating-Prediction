About Movie Rating Prediction

Movie Rating Prediction is a Machine Learning project developed using Python and Flask. The application uses a Linear Regression algorithm to estimate movie ratings based on the movie information provided by users. It also provides dataset exploration, analytics, user account management and feedback features.

🤖 Algorithm

Linear Regression

🐍 Technology

Python and Flask
